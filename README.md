# Janvi Dixit – Portfolio Website

A simple portfolio built with HTML, CSS and JavaScript only. No build step.

## Files
- `index.html` – all content (search for `EDIT HERE`)
- `css/style.css` – colors and layout (colors are at the top)
- `js/script.js` – theme, menu and animations
- `assets/images/` – photos
- `assets/documents/resume.pdf` – your resume (already added)

## Add your photo and project image
1. Save your photo as `assets/images/profile.jpg` (portrait, about 800×1000 px).
2. Save a screenshot of your project as `assets/images/project1.png`.
Until you add them, default pictures are shown.

## Update the resume
Replace `assets/documents/resume.pdf` with the new file. Keep the same name.

## Edit content
Open `index.html` and search for `EDIT HERE`. The project text comes from your CITS project report (`assets/documents/project-report.pdf`).
- A link with an empty `href=""` is hidden automatically.
- A skills group with no items is hidden automatically.

## Publish on GitHub Pages
1. Create a new public repository on GitHub (for example `portfolio`).
2. Click **Add file → Upload files** and upload everything inside this folder. Keep the folder structure. Click **Commit changes**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then **Save**.
5. Wait 1–2 minutes. Your site will be at `https://YOUR-USERNAME.github.io/portfolio/`.

Tip: a repository named `YOUR-USERNAME.github.io` gives the shorter URL `https://YOUR-USERNAME.github.io/`.
